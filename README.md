## 🚀 Featured Projects

### 🧠 Brain Tumor Classification using Fine-Tuned VGG19
- Developed a deep learning model using transfer learning with VGG19.
- Applied image preprocessing techniques including grayscale conversion, Gaussian filtering, thresholding, and augmentation.
- Achieved:
  - Accuracy: ~82%
  - F1 Score: 0.805
  - AUC-ROC: 0.86

### ✈️ Flight Ticket Price Prediction
- Built an ML regression model for predicting flight ticket prices.
- Compared multiple regression algorithms and optimized Random Forest using hyperparameter tuning.
- Achieved:
  - Adjusted R²: ~0.89
  - MAE: ~350
  - RMSE: ~550
- Deployed using Streamlit.

### 📉 Customer Churn Prediction System
- Built an XGBoost-based churn prediction system with 94% accuracy.
- Developed FastAPI REST APIs for real-time predictions.
- Containerized application using Docker for cloud deployment.

### 🪖 NCC Cadet Management Portal
- Developed a web-based portal for managing NCC cadet records.
- Implemented SQL database management for attendance, documents, and camp records.
- Digitized manual record keeping for efficient administration.
