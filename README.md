## 🚀 Featured Projects

### 🤖 Full-Stack RAG Chatbot

* Developed a **Retrieval-Augmented Generation (RAG)** chatbot for document-based question answering using LLMs, LangChain, and FAISS.
* Implemented document ingestion, text chunking, semantic retrieval, and conversational memory.
* Built REST APIs using **FastAPI** and a frontend using **React and TypeScript**, with MongoDB Atlas for data persistence.
* Integrated intent classification, lead extraction and scoring, JWT authentication, RBAC, and administrative analytics.

🔗 [Project Repository](https://github.com/dushyantrajotia/RAG-chatbot)

### 🧠 Brain Tumor Classification using Fine-Tuned VGG19

* Developed a deep learning model using transfer learning and fine-tuned VGG19 for binary tumor classification.
* Applied image preprocessing, Gaussian filtering, thresholding, and data augmentation.
* Achieved **~82% accuracy**, an **F1-score of 0.805**, and an **AUC-ROC of 0.86**.

### ✈️ Flight Ticket Price Prediction

* Built an ML regression model and optimized Random Forest using hyperparameter tuning and cross-validation.
* Achieved an adjusted R² of approximately **0.89** and deployed the model using Streamlit.

### 📉 Customer Churn Prediction System

* Developed an **XGBoost-based churn prediction system** with approximately 94% accuracy.
* Built FastAPI REST APIs and containerized the application using Docker for deployment.

### 🪖 NCC Cadet Management Portal

* Developed a web-based portal to manage cadet records, attendance, documents, and camp participation.
* Implemented SQL-based data management to improve record organization and accessibility.
